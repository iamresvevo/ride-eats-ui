# Icon catalog

2015 Lucide icons vendored from lucide-static 1.66.0, ISC. The included LICENSE.lucide preserves all upstream copyright and Feather-derived icon notices. Existing Send glyphs remain in react/send/Icon.jsx. These icons are third-party artwork behind Ride Eats UI's own component API.

Regenerate with npm run icons:generate. Letter chunks load on demand; names and search tags are separate exports.
