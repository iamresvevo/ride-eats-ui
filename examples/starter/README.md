# Ride Eats platform starter

Copy this directory to your app, then run `npm install` and `npm run dev`.

A complete local workflow is included: search, sort, select rows, create a folder, cancel, stack a discard confirmation, preserve the draft and show a toast. Data is in React state; replace the local actions with your own authorized backend endpoints. Branding, routes and authentication remain yours. The dependency is pinned to the v0.5.0 GitHub release.
